# Israel Kwamu — Full-Stack Portfolio & Nexaris Labs SaaS Showcase

Welcome to the official repository for the elite interactive developer portfolio and SaaS hub of **Israel Kwamu**, Full-Stack Web Developer and Founder & CEO of **Nexaris Labs**.

This is not a generic static portfolio. Built from the ground up using **React 19**, **TypeScript**, and **Tailwind CSS**, it acts as a fully functional platform featuring interactive advisory sandboxes, complex workflow editors, custom utility engines, and a command-line interface terminal.

---

## 🚀 Key Features & Interactive Sandboxes

1. **Dual Viewing Architectures**:
   - **Page-by-Page Mode**: Smooth paginated presentation with high-performance navigation and structural page headers.
   - **Continuous Scroll Mode**: Single infinite-scroll view with real-time active section tracking synchronized to the scroll position.

2. **Interactive CLI Developer Terminal (`Cmd + K` or `Ctrl + K`)**:
   - A fully functional console simulator supporting custom commands (e.g., `help`, `about`, `skills`, `projects`, `clear`, `email`, `socials`, `resume`).
   - Enables lightning-fast, keyboard-driven navigation across the portfolio.

3. **Interactive Technology Comparison Sandbox**:
   - Located in the **Skills** section, this allows users to drag/select frontend frameworks (Angular, React) and backend engines (Node.js, Express.js) to compare system parameters, asynchronous handling, performance, and real-time suitability.

4. **Kwamu & Co Custom Tax Calculator Modal**:
   - A highly precise calculation tool highlighting dynamic income-tax tier bracket computations, company income tax (CIT) analysis, VAT estimators, and education tax breakdowns.

5. **Visual Workflow Builder Modal**:
   - A drag-and-drop styled pipeline editor representing the automation workflows of **Nexaris Labs**, enabling users to connect nodes like *Triggers, Conditions, API Integrations, and Action Tasks*.

6. **Interactive Blog Engine**:
   - Includes real-time clap tracking, categorization, reading-time estimates, search by topic filters, and built-in clipboard sharing wrappers.

## 💻 Local Development Setup

To run this application locally, ensure you have [Node.js](https://nodejs.org/) installed, and follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/Israel-Kwamu/Israel-Kwamu-Portfolio.git
cd Israel-Kwamu-Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```
The dev server will boot up instantly. Open your browser and navigate to `http://localhost:3000`.

### 4. Build for Production
To generate highly optimized static assets inside the `dist/` directory:
```bash
npm run build
```
